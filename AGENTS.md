# Car OBD companion (Expo)

Standalone Android companion spike for Project Car — not Residence More.

- Prefer Dev Client for Classic/BLE: `npx expo prebuild && npx expo run:android`
- Simulator UI works via Expo Go (`npm start` → «Симулятор»)
- Keep secrets out of the repo; sync is a stub in `src/sync/readingsSync.ts`
- See README.md (Russian) for Classic vs BLE caveats
